# Pre-Op-to-Intra-Op
Pre-Operative to Intra-Operative: A Brain Tumor Segmentation Generalization Study

## Pretrained Model Checkpoints

Checkpoints are hosted on Hugging Face (private access):
- [IMFuse](https://huggingface.co/danishali6421/IMFuse)
- [D3Seg](https://huggingface.co/danishali6421/D3Seg)
- [mmformer](https://huggingface.co/danishali6421/mmformer)
- [M3AE](https://huggingface.co/danishali6421/M3AE)

Note: these repos are currently private. Contact the author for access.

Download with:
```bash
hf download danishali6421/IMFuse --local-dir ./checkpoints/IMFuse
hf download danishali6421/D3Seg --local-dir ./checkpoints/D3Seg
hf download danishali6421/mmformer --local-dir ./checkpoints/mmformer
hf download danishali6421/M3AE --local-dir ./checkpoints/M3AE
```
